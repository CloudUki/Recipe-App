# Recipe App

# Problem:
I was asked by my family to come up with some sort of app that they can use to find recipes when they are away from the house, out shopping, or at home. 

# Resolution:
This is the Recipe App I developed with:
- React Native
- Expo Go
- React Native Paper

# Pre Reqs:
1. This app uses Spoonaculars API so make sure you create an account and put your API key in an .env.
2. Download the Expo Go app on your mobile device.

# Start Up:
1. Clone this repo and cd to recipe-finder.
2. In a terminal, run
```
npm start
```
3. Once you run the above command, it will prompt you with a QR Code.
4. Open your camera on your phone and scan the QR Code (make sure you have Expo Go downloaded).
5. Once scanned, it will open in Expo Go, then you should be all set to use it.
